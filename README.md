## 👨‍💻 About the Portfolio

A modern, responsive, and interactive personal engineering portfolio showcasing my professional journey, technical expertise, software development projects, certifications, and achievements.

Built using **HTML5, Tailwind CSS, and Vanilla JavaScript**, the portfolio features a dark glassmorphic interface, interactive recruiter CLI terminal, dynamic project filtering, and an ATS-friendly resume viewer.

The goal is to provide recruiters, hiring managers, and engineering professionals with an engaging overview of my technical capabilities and professional experience.

## ✨ Key Features

### 1. Interactive Recruiter CLI Terminal
An interactive command-line interface that allows recruiters to explore my professional profile through predefined commands.

| Command | Description |
|---|---|
| `whoami` | Professional introduction |
| `skills` | Technical skills and expertise |
| `projects` | Featured development projects |
| `gate` | GATE examination achievements |
| `certs` | Certifications and credentials |
| `contact` | Contact and social links |
| `hire` | Professional hiring information |
| `help` | List available commands |

### 2. Dynamic Project Showcase
Explore projects through category-based filtering and interactive project cards.

**Featured categories:**
- Full-Stack Development – MERN applications, React and Node.js.
- Computer Vision & AI – YOLOv8, OpenCV, OCR and voice interaction.
- Backend Development – Django REST Framework, REST APIs, JWT authentication and Docker.

**Featured projects:**
- JobOrbit – Full-stack job-related application.
- KeepNotes-MERN – MERN-based note-taking application.
- Smart Object Detection & Voice Interaction System – AI-powered computer vision application.
- Personal Finance Tracker – React, TypeScript and Django REST Framework.
- Task Manager API – Backend application built with Django REST Framework.

### 3. System Architecture Blueprint
An interactive architecture modal explaining the technical workflow and components of my Smart Object Detection & Voice Interaction System.

Highlights:
- Real-time object detection using YOLOv8.
- Image processing using OpenCV.
- Voice recognition and speech interaction.
- Text-to-speech output.
- Modular system architecture.

### 4. ATS-Friendly Resume Viewer
A dedicated resume interface designed for recruiters.

Features include:
- Professional resume presentation.
- Print-friendly formatting.
- One-click PDF export through browser printing.
- Clipboard copy utilities.
- Recruiter-focused professional summary.

### 5. Modern UI & Interactive Experience
- Dark glassmorphic design.
- Responsive layouts for desktop, tablet and mobile.
- Ambient glow and particle network effects.
- Scroll-reveal animations.
- Animated metric counters.
- Smooth navigation and transitions.
- Custom typography and icon integration.

## 🚀 Getting Started

Follow these steps to run the portfolio locally.

**1. Clone the repository**

```bash
git clone https://github.com/Osmaditya/portfolio.git
```

**2. Navigate to the project directory**

```bash
cd portfolio
```

**3. Launch the application**

Open `index.html` directly in your browser.

Alternatively, use the VS Code Live Server extension for local development.

No additional package installation or build process is required.
