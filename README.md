# Aditya — Software, Cloud & AI/ML Engineer Portfolio

A responsive, interactive personal engineering portfolio built with semantic HTML5, Tailwind CSS, and Vanilla JavaScript. Designed with a dark glassmorphic UI, an interactive recruiter CLI terminal, category-filtered project showcases, and an ATS-friendly print-ready resume viewer.

## Features

- **Interactive Recruiter CLI Terminal:** Query profile highlights directly via commands (`whoami`, `skills`, `projects`, `gate`, `certs`, `contact`, `hire`, `help`).
- **Dynamic Project Showcase:** Filterable portfolio cards spanning Full-Stack MERN (`JobOrbit`, `KeepNotes-MERN`), Computer Vision & Voice AI (`YOLOv8` + `OpenCV` + `OCR`), and REST APIs (`Django REST`, `JWT`, `Docker`).
- **System Architecture Blueprint Modal:** Interactive pipeline breakdown for the Smart Object Detection & Voice Interaction System[cite: 1].
- **Print-Ready Resume & Executive Brief:** Built-in ATS-ready resume modal with one-click PDF export (`window.print()`) and clipboard copy utilities[cite: 1].
- **Responsive Glassmorphic Design:** Custom Tailwind configuration with ambient glow effects, scroll-reveal animations, metric counters, and a particle network canvas[cite: 1].

## Tech Stack

- **Markup & Styling:** HTML5, Tailwind CSS (CDN), Custom CSS3 Animations & Print Media Queries[cite: 1]
- **Interactivity:** Vanilla JavaScript (ES6+), IntersectionObserver API, HTML5 Canvas[cite: 1]
- **Typography & Icons:** Inter, JetBrains Mono (Google Fonts), Font Awesome 6[cite: 1]
- **Hosting & CI/CD:** GitHub + Netlify Continuous Deployment
